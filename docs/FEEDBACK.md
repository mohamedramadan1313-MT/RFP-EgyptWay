# Feedback and support

Send feedback to **mohamedramadan1313@gmail.com** with the subject **RFP-EgyptWay — Feedback**.

Copy this template into your email:

```text
Screen / step:
Approximate date and time, including timezone:
Review method (human / numeric rules / local / cloud if enabled):
What I tried:
What I expected:
What happened:
Error code, if shown:
Can I reproduce it? If yes, how?
Suggested improvement:
```

Useful observations include an irrelevant retrieved page, a quotation assigned to the wrong requirement, a requirement mistaken for an offered specification, missing evidence treated as non-compliance, a numerical contradiction, or a difficult workflow.

Do not attach confidential tender or proposal content, credentials, or personal information. If you choose to share a support export, review it first. General feedback can describe the problem without reproducing the document.

GitHub issues are public: use them only for non-confidential product questions and suggestions. Security concerns should be sent privately by email with the subject **RFP-EgyptWay — Security report**. Do not post an exploit, access token, or customer data publicly.

Support is handled by the project owner. We do not promise continuous monitoring, immediate replies, or automatic changes to the application. Feedback is reviewed before fixes are tested and released.
