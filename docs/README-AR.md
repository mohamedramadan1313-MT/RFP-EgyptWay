# RFP-EgyptWay — مراجعة العروض بالأدلة

يساعد البرنامج فريق المراجعة على تقييم العروض الفنية والمالية مقابل متطلبات المناقصة، ومراجعة الإحالات وتسجيل القرار البشري وإخراج التقارير.

هذه صفحة تعريف ودليل استخدام، وليست نشرًا للكود المصدري أو مستندات العملاء. البرنامج يقيّم المستندات التي تقدمها للمراجعة، ولا يقدم خدمة البحث عن المناقصات المنشورة.

**التجربة الخارجية لم تُفتح بعد.** نكمل فحوص التشغيل ومعالجة تنبيه أمان لدى جوجل قبل إرسال الدعوات. لا تتجاوز أي تحذير أمان في المتصفح.

لطلب إشعار عند إتاحة التجربة، أرسل إلى **mohamedramadan1313@gmail.com** بعنوان «طلب تجربة RFP-EgyptWay». اذكر طبيعة عمل المراجعة واللغة المناسبة، دون إرسال عروض سرية أو كلمات مرور.

## رحلة الاستخدام

1. تستلم حسابك ورابطك وموعد التشغيل بعد إتاحة التجربة.
2. تنشئ مناقصة وتضيف المتطلبات والعروض والمستندات المسموح برفعها.
3. تراجع النص المستخرج والبنود قبل التقييم.
4. تختار النطاق الفني أو المالي أو كليهما، ثم الموردين والبنود.
5. تختار المراجعة البشرية أو القواعد الرقمية أو النموذج المتاح، وتراجع الموقف قبل التشغيل.
6. تنتظر اكتمال التشغيل ثم تضغط «فتح البنود».
7. تراجع الصفحة والاقتباس ومدى دعمهما للحكم؛ وجود الاقتباس وحده لا يثبت صحة الاستنتاج.
8. تسجل قرارك وتعليله في نسخة جديدة.
9. تختار نسخ التقارير المطلوبة وتصدرها.
10. ترسل ملاحظاتك بالبريد دون محتوى سري.

النموذج قد يخطئ، ونقص الدليل ليس عدم امتثال تلقائيًا. النسخة للتجربة ودعم القرار، وليست اعتمادًا تلقائيًا للمورد. التشغيل المحلي على معالج دون GPU قد يستغرق عدة دقائق للبند.
